# dsh-comfy-enhance

给 [DeepSeek Harness](https://github.com/deepseek-ai) 用的 ComfyUI 面板套件。一个 bundle 里包含四个模块，在插件页里可以分别开关。

> 它不依赖 ComfyUI 的浏览器界面——Host 端直接调用 ComfyUI 的 HTTP 接口（`/system_stats`、`/history`、`/view`），所以只要 ComfyUI 进程开着就能用。

## 模块

### 1. 侧边栏状态卡片

左侧边栏底部常驻，不用离开对话就能看到引擎状态：

- 在线 / 离线、ComfyUI 版本
- 队列：运行中 / 等待中
- 显存占用（带进度条，运行中吃紧时变色）
- 最近一次产出的耗时和文件名

### 2. 相册标签页

右侧边栏的输出图画廊：

- 缩略图按日期分组（今天 / 昨天 / N 天前）
- 大图预览，点右下角放大到全屏，`Esc` 关闭
- 每张作品的完整信息：提示词（正 / 负，MOSS 的结构化 JSON 会自动抽出 caption）、模型、采样参数
- 顶部「正在生成」条实时显示运行中任务的提示词
- 「清空」只影响插件里的显示，不碰 ComfyUI 的历史记录和输出文件

### 3. 画框标签页（MOSS）

**MOSS-Image 专用**的版式画板。产出的不是普通文本提示词，而是 MOSS 的 layout JSON（`abs_centralized` + `yxyx` 坐标），别的模型认不了。

> **注意：MOSS 画板建议配合 MOSS 提示词 skill（`moss-image-prompt-enhancer`）一起使用，效果更好。**
>
> 画板负责版式、画框和参数；画面描述、文字内容与提示词的写法交给这个 skill 来生成。两者配合更容易拿到好的构图与画面质量。

- 读取 ComfyUI 工作流里 `CreateBoundingBoxes` 节点的内容
- 拖动移动、右下角缩放、右键删除
- 双击框内编辑：text 框写字面内容，其它框写描述
- 整图描述（summary）—— 对应 `MOSSImageLayoutPrompt` 的 prompt 输入
- 比例 / 像素量跟随工作流的 `ResolutionSelector`，尺寸自动对齐 16 的倍数
- 叠图参考：从相册选图或选本地图片，垫在画框下面对着画
- 全屏大视图：左侧画布 + 右侧框列表，重叠的框也能单独选中
- 一键把 MOSS layout 发给 agent 补描述
- 编辑内容按工作流文件自动存草稿，切换 tab、刷新都不丢

### 4. 独立画板工作台

左侧边栏「自动化任务」下方新增入口（插件页可单独开关），点开在主内容区打开全屏画板工作台，不占用右侧边栏标签页。

打开后先选一种出图方式：

| 方式 | 适合 | 依赖 |
| --- | --- | --- |
| **MOSS 画板模式** | MOSS-Image：画框、版式、快速生成 | 本机 ComfyUI |
| **在线 API** | 远程出图（OpenAI 兼容 / MiniMax） | 一个可用的 API 端点与 Key |
| **本地文生图** | 非 MOSS 的 DiT 模型（Flux 等）：纯提示词出图 | 本机 ComfyUI |
| **漫画工作台** | 分格、气泡、逐格或整页出图，做条漫 / 页漫 | 本机 ComfyUI + MOSS 模型（整页出图时） |

#### MOSS 画板模式

- 与画框标签页同款画板：标尺 / 参考线 / 吸附 / 双击加框 / 右下角缩放 / 预览
- **画框支持旋转（实验性）**：选中框后拖动顶部圆点旋转；MOSS 的 bbox 不支持旋转，生成时按外接矩形提交，效果未经验证
- 顶栏：工作流、参考图与不透明度、画布比例 / MP、种子（随机 / 固定）、标尺、模型设置、加框、快速生成、停止
- 右栏：框列表、选中框编辑、整图描述、负面提示词、相册入口
- 参数与侧边栏画板**完全隔离**（草稿、模型 / 采样、标尺、主题各自独立）；可用「导入侧边栏」一次性把侧栏画板复制过来

#### 在线 API

- 端点 / API Key / 模型都能填，`获取列表` 直接从端点的 `/v1/models` 拉模型名
- OpenAI 兼容与 MiniMax 两套参数：尺寸、质量、背景、输出格式、宽高比、`prompt_optimizer`、水印、种子
- 支持参考图编辑（`/images/edits`）；出图可保存到指定目录并进相册
- 请求由 Host 代理转发（同源），远端不需要跑在本机；出图过程不占用本机显存

#### 本地文生图

- 纯提示词出图，不涉及画框
- **模型与 LoRA 各收成一行虚线摘要**，点开是弹窗：UNET / CLIP / VAE / CLIP 类型在「生成设置 · 模型」里，LoRA 列表在「生成设置 · LoRA」里（最多 4 个，行前手柄拖动调整应用顺序）
- **采样器 / 调度器是下拉**，候选值取自 ComfyUI 自己报的列表（换节点包会自动多出新选项），当前值不在列表时自动补一条
- 分辨率：两个数字框直接填出图尺寸（8 的倍数对齐），点框里改完**离焦或回车**才生效；下面是 8 个比例预设（1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 3:2 / 2:3 / 21:9，都在 1MP 上下）
- **倍率**：为 1 时直接提交框内的值；不等于 1 时按倍数乘算后再提交，行尾显示 `→ W × H`（和实际提交用的是同一个值）
- 种子：固定，或开启**随机模式**（每次生成自动换一个并回填到输入框）
- 出图进度以遮罩压在预览大图上（排队中 / 正在生成 + `n/m` + 秒数 + 进度条），完成后自动刷新相册并切到新图
- 预览顶栏「提示词」按钮：弹窗查看该图的正 / 负提示词（图片本身没带参数时按需读 PNG 内嵌数据）
- 「生成」吸在侧栏底部，滚多远都够得着

#### 漫画工作台

毫米制的漫画排版与出图：**分格 → 写内容 → 逐格或整页出图**。

- 画布按毫米算（B5 176×250 / 条漫 105 宽），300dpi 换算，网格可开关；打开即铺满舞台
- 分格：四格 / 上下二段 / 斜切两分 / 2×3 / 随机分格；双击加格、拖顶点改形、拖格子移动、`K` 刀切
- 吸附：磁性网格 + 邻近格子的边/中线（洋红参考线）+ 三分线（青色虚线），按住 `Alt` 关闭
- 多选：`Shift` 点选，整组拖动，`Del` / `Ctrl+D` / 方向键作用于全部选中，右栏可对齐与等距分布
- 气泡 8 类（对白 / 心声 / 喊叫 / 低语 / 方框 / 旁白 / 拟声 / 自由），自动缩字与竖排
- 多页：新建 / 删除 / 切换，每页独立分格；`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做 30 步（跨页）
- **逐格出图**：每格单独写提示词，单格生成或批量排队，走「本地文生图」那套模型
- **整页出图**：格子矩形 → MOSS layout 的 object 框、气泡 → text 框，一次出整页（四格各是不同镜头）
- **台词入图**（默认开）：气泡文字写进 MOSS 的 text 框，由模型直接把对白画进画面；关掉则回到矢量气泡叠加
- 整页描述 / 画风：作为 layout 的 `summary.caption` 发出去，锁整页主调
- 导出：整页 300dpi PNG、整本 ZIP、JSON（跨机器备份与交给 agent）
- 编辑内容自动存浏览器（防抖 500ms），重开面板自动恢复；保存时把当前文档写进 `~/.dsh/comic/state.json`，agent 侧 `comic_status` 能读到真实排版
- agent 工具：`comic_import`（设为工作台草稿）、`comic_status`（看当前页数/格数/提示词）、`comic_fill`（按既有分格回填内容，几何不动）


## AI 提示词

两个出图面板（本地文生图、在线 API）共用同一套提示词工具：

- **AI 写/润色**：提示词框下方的橙红渐变按钮，悬停上浮并亮起光晕，按下整体下沉；生成中显示进度
- **额外要求**：按钮下面的输入框，作为指令传给模型；留空则沿用「用提示词本身当指令」的老行为
- **固定提示词（钉住）**：把质量前缀（例如正向 `masterpiece, best quality…`、负向 `worst quality…`）存进弹窗，生成时按「固定, 正文」拼在最前面，英文逗号分隔。按钮三态：未设置浅灰、生效橙色、已设置但停用灰虚线；输入框里的正文始终不动
- **写作规则**：标签式（SD）/ 自然语言两套自定义规则，可分别编辑
- **对话记录**：按风格保存每一轮输入与输出，最多 50 条
- **模型来自 DSH**：润色用哪个模型直接读 DSH 的模型目录——按 provider 分组的下拉、带各自的思考档位，不再手打模型名

## 安装

### 让 agent 装（推荐）

把仓库克隆到任意位置，然后在 Harness 会话里说：

```
用 plugin_manager 从 <克隆目录> 安装这个 bundle
```

### 手动装

```bash
# 1. 克隆
git clone https://github.com/<you>/dsh-comfy-enhance.git

# 2. 链接到 profile（Windows 用 junction）
cmd /c mklink /J "%USERPROFILE%\.dsh\profiles\<profile>\node_modules\dsh-comfy-enhance" "路径\dsh-comfy-enhance"

# 3. 在 profile 的 cordis.patch.yml 末尾追加
```

```yaml
- insert:
    - id: dsh-comfy-enhance
      name: dsh-comfy-enhance
```

重启 Harness，插件页里会出现「ComfyUI 增强」。

## 首次使用

1. 安装并启用 bundle 后刷新页面：右侧边栏出现「相册」「画框」标签页，左侧边栏底部出现状态卡片。
2. 打开「画框」标签页：如果 ComfyUI 的 workflow 目录里还没有画板工作流，插件会自动装入内置的空白模板 `moss-bbox-canvas.json`（已有同名文件则不覆盖）。
3. 点顶部「模型」打开「生成设置」，选好 UNET / CLIP / VAE（默认是 MOSS-Image 的 DiT 三件套），LoRA 可以留空或最多加 4 个。
4. 在画布上拖框或双击空白加框，写完整图描述后：
   - 「快速生成」：直接按当前版式出一张预览图；
   - 「发给 agent」：把版式交给对话，继续补描述或润色（配合 MOSS 提示词 skill `moss-image-prompt-enhancer` 效果更好）。
5. 生成过程中可以「停止」，完成后新图会进入相册，并自动成为下一轮的参考图。
6. 左侧边栏「Image 工作台」入口打开的是独立工作台：先选 **MOSS 画板 / 在线 API / 本地文生图 / 漫画工作台**，四者的参数与草稿各自独立。

## 配置

`cordis.patch.yml` 里的 `comfyUrl`，默认 `http://127.0.0.1:8188`：

```yaml
- insert:
    - id: dsh-comfy-enhance
      name: dsh-comfy-enhance
      config:
        comfyUrl: http://127.0.0.1:8188
```

也可以用环境变量 `DSH_COMFY_URL` 覆盖。

**为什么走 Host 代理**：Web GUI 可能从另一台机器打开（比如经 Tailscale），浏览器里的 `127.0.0.1` 是访问者自己的回环地址，不是跑 ComfyUI 那台。所以所有请求都由 Host 端代理，同源转发。

## 模块怎么开

插件页 → 找到「ComfyUI 增强」→ 点进去：

```
侧边栏状态卡片                 [开]
相册标签页                     [开]
画板标签页（MOSS）             [开]
```

关掉哪个，对应界面就不出现（画板关掉后 tab 类型会注销，右栏入口直接消失）。

「Image 工作台」是第四块，入口在左侧边栏，打开后在同一个页面里切四种模式（MOSS 画板 / 在线 API / 本地文生图 / 漫画工作台），四种模式的参数与草稿互相独立。

开关存在浏览器 localStorage，同一浏览器刷新后保持。

## 工作流文件

画框模块直接读写 ComfyUI 的 `user/default/workflows` 目录，路径从运行中实例的 `/system_stats.argv` 自动推导，不需要手填。

首次打开画板时，如果目录里还没有 `moss-bbox-canvas.json`，插件会把内置的空白版画板工作流复制进去（已存在则绝不覆盖）；这样新安装的用户不用自己准备模板就能直接画框。

读取和保存都会做路径校验（拒绝 `..`、非 `.json`、目录外路径），保存前自动留一份 `.bak`。

## 内部路由

| 前缀 | 用途 |
|---|---|
| `/plugin/comfy-status/*` | 状态快照、相册、图片代理、输出目录与 PNG 内嵌参数、改词重生成、终止任务、采样器选项、SSE 执行事件、启动 / 停止 ComfyUI |
| `/plugin/comfy-canvas/*` | 工作流读写、比例选项、模型 / LoRA 选项、按版式或提示词生成、在线 API 代理（模型列表 / 出图 / 存盘）、提示词润色与写作、DSH 模型目录、漫画草稿与实时状态（`comic-draft` / `comic-state`） |

前缀沿用早期两个独立插件的名字，没有跟着包名改——它们不出现在 UI 里，改动的收益小于风险。

## 已知限制

- 画框模块只支持带 `CreateBoundingBoxes` 节点的工作流；其它工作流打开会提示没有画板
- 画板里的「快速生成」用内置模板本机出图，不依赖历史；但模板引用的模型文件必须已经装在 ComfyUI 里，缺失会在提交前提示
- 叠图参考里本地选的图片不跨页面刷新（浏览器 blob URL 的限制），相册来源的会保留
- 画框草稿存在浏览器 localStorage，换浏览器不同步
- 画框产出的 layout JSON 只有 MOSS-Image 认，别用在 SD / Flux 上
- 画框旋转属于**实验性功能**：MOSS 的 bbox 是轴对齐的，倾斜框会按外接矩形提交，最终画面是否跟随倾斜并不确定，请自行验证效果
- 在线 API 的尺寸是端点给定的固定枚举（`1024x1024` / `1536x1024` / `auto` 等），因此**不提供倍率**——乘出来的尺寸上游会拒
- 固定提示词目前只作用于「本地文生图」的生成；AI 写/润色收到的是不含它的正文（避免质量词被模型改写后重复两遍）
- LoRA 按列表顺序依次串联，顺序会影响出图；最多 4 个
- 按钮的悬停光晕与上浮只在有指针的设备出现（触摸屏不触发）
- 漫画工作台的**逐格出图**走「本地文生图」那套非 MOSS 模型，**整页出图**才走 MOSS；两者要分别配好模型
- 漫画的整页出图依赖 MOSS 的 layout 能力，文本框位置决定台词的落点，气泡样式（笑声、拟声）目前靠描述词表达
- 漫画导出暂不支持 PSD，只有 PNG / ZIP / JSON

## 样式约定

插件有三个样式注入点，公共规则只写在一处：

| 注入点 | 放什么 | 谁挂 |
| --- | --- | --- |
| `ensureBaseStyle()` | 公共：`.dshCanvasBtn` / `.dshCanvasPicker` / `.dshCanvasOption`、surface 主题变量、主题图标、流光标题、全部 keyframes | 每个面板块的根组件都先调它 |
| `AlbumStyles` | 相册页与查看器独有（`.dshComfyAlbum-*`、`.dshComfyViewer-*`） | 相册 tab、查看器 |
| `Styles` | 画布独有（画板、标尺、画框） | 画框 tab、工作台画布 |

四条规矩：

1. **被两个以上界面用到的样式写进 `ensureBaseStyle()`**，不要写进面板块的表——工作台的三个面板视图只挂基础表，写别处等于没写（历史上因此丢过进度环 keyframes、主题图标和 surface 变量）。
2. **面板块根组件先调 `ensureBaseStyle()`**，再渲染自己的东西。
3. **同行等高用 `align-self: stretch` 跟随该行最高元素**，不要写死 `height` 去猜——固定值会和按行高推算的邻居差 3～4px。
4. **同一个控件的外观只定义一次**：类管外观，行内只管尺寸与布局。两边都写尺寸时，删掉一边另一边就冒出来咬人。
